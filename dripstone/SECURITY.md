# Security policy

Dripstone is not yet published as a general-availability release. Until the
repository is public, report vulnerabilities privately to the maintainer:

- Email: nicholas@papachriston.com

Please include the affected version or commit, the feature flags required to
reach the issue, and a minimal reproduction. Do not open a public issue for
an unfixed vulnerability, and do not include live credentials in the report.

There is no bug bounty. Fixes are shipped on this repository; crates.io is
intentionally disabled (`publish = false`) until a release is approved.
